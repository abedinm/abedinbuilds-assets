Launch-Ready Portfolio Template — Edit Guide

Everything lives in one file: index.html. Open it in any text editor (VS Code, Notepad, anything). No installs, no build tools.

1. Make it yours (5 minutes)

  1. Name & title: search for Aria and replace every match with your name. Update the <title> and <meta name="description"> at the top.
  2. Headline & intro: edit the text inside the <section class="hero"> block.
  3. Contact: search for hello@example.com and 8801XXXXXXXXX — replace with your email and WhatsApp number (country code, no + or spaces).
  4. Social links: in the <footer>, replace each href="#" with your profile URLs. Delete any you don't use.

2. Swap the images

All images are in the images/ folder. Replace them with your own photos/screenshots — keep the same file names and you don't have to touch the code at all. Or use new names and update the src="images/..." paths:

  • portrait.svg — your photo (square works best)
  • project-1.svg … project-4.svg — screenshots of your work (landscape)
  • about.svg — a second photo or workspace shot
JPG and PNG work exactly the same: src="images/portrait.jpg". Keep images under ~300 KB each for fast loading.

3. Rebrand the colors & fonts (30 seconds)

At the top of index.html there is one marked block:

:root{
  --bg:#0b0d12;        /* page background */
  --brand:#6ea8fe;     /* main accent color */
  --brand-2:#9b8cff;   /* gradient partner */
  --radius:18px;       /* corner roundness */
  ...
}

Change --brand and --brand-2 to your two brand colors — every button, link, and gradient updates automatically. For fonts, change the Google Fonts <link> in the <head> and the --font-head / --font-body names.

4. Edit the sections

  • Services: three <div class="card"> blocks — edit titles and text. Copy-paste a block to add a fourth.
  • Projects: four <a class="project"> blocks — set the href to the live project URL, swap the image, edit the caption.
  • Testimonial: edit the quote and name in the <div class="quote"> block. Delete the whole section if you don't have one yet.
  • Trust bar: the row of company names under the hero — replace with clients/schools, or delete the <div class="trust"> block.

5. Put it online (free)

  • Netlify: go to app.netlify.com → drag the whole folder onto the page. Live in 30 seconds.
  • GitHub Pages: push the folder to a repo → Settings → Pages → deploy from branch.
  • Vercel: vercel.com → New Project → import the folder.
